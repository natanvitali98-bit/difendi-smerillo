# Difendi Smerillo

Gioco di difesa in pixel art ambientato a Smerillo e nelle sue frazioni.

Gioca: https://natanvitali98-bit.github.io/difendi-smerillo/

## Pubblicare
Prima di ogni commit del gioco lancia `python3 pubblica.py`: mette una versione nuova in `index.html` e in `version.json`, così chi ha il gioco sulla schermata Home vede «C’è una versione nuova».
